v4.6.0 — Travel Story

這版把「布丁狗 × 烏薩奇的九州旅行」變成真正的每日情境敘事。

完成項目：
- D1–D10 改用使用者提供的 10 張完整每日主題圖，不再用兩張角色圖＋小圖章拼成每日圖。
- 每日主標題固定單行；手機版自動縮字，不再把「天神+大名+Canal City」拆成兩行。
- 每日情境圖啟動時全部 preload/decode，切日期不再等待圖片才出現。
- 天氣區使用新雨衣烏薩奇。
- 訂位／搶票使用「布丁狗確認票券」＋「烏薩奇衝刺」，兩張圖分欄排列、完全不重疊。
- 購物清單／記帳／記事的外框與內部內容增加留白。
- 餐飲安排改成 Day / Time / Status 的簡潔資訊列，餐廳名稱獨立成主標。
- 附近找吃的維持在美食頁最上方。
- 每日行程最後保留飯店導航，並換成新雙角色回飯店休息圖。
- 每日情境圖可點擊觸發雙旅伴微互動；保留原本的角色小彩蛋，但不增加高頻干擾動畫。
- 不恢復楓葉、generic rabbit emoji 或無功能貼紙列。
- Firebase Auth / Database Rules / 私人 trip content 架構完全不變。
